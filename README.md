# This is the frontend code for the Markdown to HTML converter
Make sure you have started the backend code already from the backend branch of this repo
also please start this code on the same machine as backend 

steps to start the project on local machine - 
Run the following commands on a terminal/command prompt
1. clone the project - git clone https://github.com/prashant-1999/Vayuz-assignment.git
2. switch to the branch backend - git checkout frontend
3. Run the command - npm i
4. Run the command - npm run start
5. Once the frontend application is running on your local machine on a port e.g. localhost:3000, open the localhost:3000
6. Use the application
