# This is the backend code for the Markdown to HTML converter

Please make sure you have latest Node.js installed on your system
steps to start the project on local machine - 
Run the following commands on a terminal/command prompt
1. clone the project - git clone https://github.com/prashant-1999/Vayuz-assignment.git
2. switch to the branch backend - git checkout backend
3. Run the command - npm i
4. Run the command - npm run start

you should be able to see the following output on the console - 
  WebSocket server is running...
  Server is running on port 5000

Switch to frontend branch of this repo for the next steps
